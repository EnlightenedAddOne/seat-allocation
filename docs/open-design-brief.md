# Open Design 设计任务 Brief —— 餐厅座位分配系统（自助小火锅）

> 用法：把本文件内容（或下面的【任务描述】段）作为 prompt 贴进 Open Design，选择 **Prototype / Web UI** 模板 + 一套合适的设计系统后 Send。产出物给我（DSH agent）集成回单文件应用。

---

## 一、项目背景

一个自助小火锅店的**座位分配系统**（类似影院在线选座），目前是单文件 HTML 应用，运行在前台平板/电脑浏览器，**离线可用、零外部依赖**，数据存浏览器 localStorage。已有完整业务逻辑（座位状态、连续空位推荐、排队、拆坐、移位、统计），**本次只做前端视觉与信息架构优化，不重写业务逻辑**。

## 二、需要设计的界面清单（共 11 个视图/弹窗）

1. **主界面（核心）**：顶部 = 标题 + 实时统计条（总座位/空/占用/清理中/排队）；下方 = 座位图（按区排列的排式座位，每排一个名称 + 若干座位格）；右侧 = 排队队列面板；工具栏 = 来客入座 / 加入排队 / 布局设置 / 统计 / 重置今日。
2. **来客入座弹窗**：人数步进器（−/＋）+ 快捷按钮 1–6 + 备注输入 + 主按钮「查看可选位置 →」。
3. **选位模式**：座位图上**所有符合条件的连续空位**整块蓝色高亮，★ 标记推荐方案（best-fit 贴边）；底部浮出方案条列出全部方案（可点击）；顶部横幅提示"正在为 N 人桌选位"。
4. **确认入座弹窗**：显示所选具体座位号列表 + 「确认入座 / 取消」。
5. **无空位弹窗**：提示无法连坐 + 两个可选方案块：**拆坐方案**（如 4=2+2，🔗 标记）与**移位拼座方案**（移动某桌腾出连座）+ 加入排队。
6. **拆坐合并提示条**（座位图上方横幅）+ **合并确认弹窗**（含"客人拒绝"选项）。
7. **移位拼座确认弹窗**：逐桌列出"原位置 → 目标位置"，每桌一个「这桌拒绝」按钮 + 「全部同意，执行」。
8. **座位操作弹窗**（点某占用座位）：桌信息（位置/人数/入座时长/标记）+ 离座（清理 N 分钟/立即空）+ 提议合并 + 标记免打扰。
9. **布局设置弹窗**：排列表（名称输入 + 座数输入 + 删除）、添加一排、两个开关（允许拆坐 / 允许移位拼座）、恢复演示布局、保存。
10. **营业统计弹窗**：指标卡片网格（接待桌数/人次、平均就餐时长、上座率、平均/P90 等待、拆坐合并移位次数与拒绝数、空区间、建议接受率）+ 「仿真对比」按钮 + 4 行配置对比表。
11. **排队面板项**：人数、已等待时长、预计等待分钟、操作按钮（安排入座 / 📦移位拼座 / 移出）。

## 三、座位状态视觉语义（必须清晰区分）

| 状态 | 含义 | 现用色 |
|---|---|---|
| 空位 | 可选 | 浅灰底 |
| 占用 | 有人，格内显示人数 | 红底白字 |
| 清理中 | 倒计时 | 琥珀/橙 |
| 候选 | 当前选位模式的可选块 | 蓝色高亮 |
| 推荐 | best-fit 方案 | 蓝底 ★ 角标 |
| 拆坐中 | 该桌被拆分 | 红色 + 🔗 角标 |
| 免打扰 | 不参与移位 | 红色 + 🚫 角标 |

## 四、设计约束（硬性）

- **单文件 HTML**：CSS 内嵌 `<style>`，无 CDN、无外部字体、无框架依赖；必须离线可用。
- **中文界面**，字号偏大（平板操作），按钮触控友好（≥44px 建议）。
- 使用场景：**晚高峰 6–7 点忙碌时段**，店员单手快速操作 → 高对比、状态一眼可辨、误操作率低。
- 座位图要求：像**影院选座**一样直观，分区（A/B/C/D）视觉分组清晰，排与排之间有呼吸感。
- 色调方向：温暖干净的餐饮氛围（暖白/米色基调 + 克制的强调色），不建议纯黑高冷风。
- 如果重排 DOM 结构：请**保留现有元素 id 契约**（或输出一份"区块 → id 映射表"），我会把新样式套回现有逻辑。
