# 餐厅座位分配系统（自助小火锅）

单文件 HTML 网页应用：**零依赖、双击即开、离线可用**。座位数据持久化在浏览器 `localStorage`，刷新/关店重开不丢。

## 功能

- **座位布局设置**：排式座位模型，可增删排、改排名称（A区/靠窗/第N排）和每排座数
- **影院式选座**：店员输入客人数 → 系统列出所有符合条件的**连续空位** → ★ 推荐 best-fit 贴边方案（从最小空块开始坐、块内贴边，避免碎片）→ 确认入座 → 座位变红显示人数
- **离座 → 清理 → 空**：客人离座进入清理倒计时（默认 3 分钟，可立即空），到点自动释放并与相邻空位合并
- **排队队列**：凑不出连续空位时可加入排队；空出大块后该桌"安排入座"按钮自动亮起
- **拆坐 + 自动合并**（一人一锅店型，可在布局设置里开关）：无整块时按 `2+2 / 3+1` 拆开先坐（🔗 标记），出现足够大的连续块后自动提议合并；"客人拒绝"后不再对该桌提议
- **移位拼座**（高峰期可选模块，可在布局设置里开关）：移动 1–2 桌（整桌、原子）拼出大块消化排队/来客；被移桌需同意，可标记免打扰🚫 或记录拒过移位✗
- **重置今日**：一键清空占用/清理/排队，保留布局

## 使用

1. 双击打开 `index.html`
2. 点「⚙️ 布局设置」按实际店面设置座位布局
3. 来客时点「🪑 来客入座」输入人数，系统列出可选位置，选一个确认
